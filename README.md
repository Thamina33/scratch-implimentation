# Machine Learning From Scratch

Implementing machine learning algorithms from scratch using Python and NumPy to understand how they work internally, without relying on high-level ML libraries.

## Algorithms

- Linear Regression
  - Ordinary Least Squares
  - Gradient Descent
- Logistic Regression
- K-Nearest Neighbors (KNN)
- More algorithms will be added as I learn them.

## Goal

The goal of this repository is to strengthen my understanding of machine learning concepts by implementing the algorithms myself, including their core mathematics, parameter updates, predictions, and evaluation.

## Tech Stack

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn for comparison and evaluation where needed
